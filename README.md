## 📊 Quick Pattern Recognition

- **Sorted array + pairs** → Two Pointers
- **Contiguous subarrays** → Sliding Window
- **Linked list cycles** → Fast & Slow Pointers
- **Searching sorted space** → Binary Search
- **Optimization problems** → Dynamic Programming
- **Locally optimal** → Greedy
- **All combinations** → Backtracking
- **Connected elements** → Graph Algorithms
